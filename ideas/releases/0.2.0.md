## Candidate Features

### App platform refactor

Labels: `architecture`, `performance`, `distribution`.

Goal:

- Move milXdy from independently booted feature scripts into a shared app platform.

Release points:

- First-party app registry in `src/shared/firstPartyApps.json`.
- Shared app lifecycle and runtime-driven lazy loading.
- Registry-driven build entries, assets, permissions, and cost metadata.
- Public app SDK documentation in `docs/APP_SDK.md`.

### Shared runtime and Performance modes

Labels: `architecture`, `performance`.

Goal:

- Reduce X/Twitter startup and scroll cost while making future apps obey shared runtime budgets.

Release points:

- Separate Appearance intensity from Performance mode.
- Support Fast, Balanced, Full, and Developer modes.
- Use one scanner/runtime/scheduler path instead of each app independently scanning and polling.
- Keep disabled apps from importing heavy bundles wherever possible.

### Shared overlay dock and app panels

Labels: `ux`, `architecture`.

Goal:

- Make dockable apps feel like one platform instead of unrelated floating widgets.

Release points:

- Shared overlay dock.
- Shared app frame and panel behavior.
- Docked app surfaces for RemiNet Chat, Postreader, Beetol, Miladychan, Music, and Maxxer-style tools where applicable.

### Miladychan Portal

Labels: `miladychan`, `ux`, `experimental`.

Goal:

- Ship a first Miladychan portal app without pretending it is the final Miladychan live-board/deck experience.

Release points:

- Docked board/thread browser.
- Miladychan background fetch allowlist.
- Public framing: companion/portal, not replacement social surface.

### Music MVP

Labels: `music`, `integration`, `experimental`.

Goal:

- Ship the local music app foundation and make the lifestyle-radio direction explicit.

Release points:

- Docked local music surface.
- Library/playlists/radio groundwork.
- ISRC enrichment path using local metadata, Chromaprint, optional AcoustID key, and MusicBrainz lookup.
- `npm.cmd run verify:music` as a release check.

### Docs and product framing

Labels: `docs`, `ux`.

Goal:

- Explain the new platform model and the philosophical shift toward a customizable Remilia companion.

Release points:

- Update roadmap, user guide, install/update docs, troubleshooting, README, and docs index.
- Explain app platform, performance modes, optional apps, Miladychan Portal, and Music MVP.
