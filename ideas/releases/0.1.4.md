## Release Goals

- Add Max/Moderate/Min setup presets.
- Make the popup and X surfaces feel more cohesive.

## Planned Features

### Settings presets

Labels: `settings`, `ux`.

Preset concepts:

- **Max**: visually invasive Remilia/Milady reskin where X becomes mostly unrecognizable, with the highest Maxxer treatment intensity.
- **Moderate**: recognizable X layout with visible Remilia/Milady chrome, marked-surface styling, and balanced Maxxer treatments.
- **Min**: mostly original X appearance with restrained milXdy controls and lightweight Maxxer markers.

UX notes:

- Show what each preset changes.
- Do not erase stats, tokens, imports, manual lists, or whitelist data.
- Consider "Apply preset" plus "Reset to defaults."
- Preserve direct per-feature settings for users who want manual control.

### RemiNet-style visual polish

Labels: `reminet`, `maxxer`, `ux`.

Targets:

- More consistent badge, poke, Beetol, Maxxer, and popup styling.
- CSS pass for Max mode, including broad X chrome reskin only in Max.
- Refactor Miladymaxxer visual treatments around Max/Moderate/Min.
- Preserve stable dimensions and readability.

### X chrome reskin surfaces

Labels: `ux`, `maxxer`, `reminet`.

Targets:

- Apply Remilia/Milady styling to high-visibility X surfaces when Max or Moderate presets are active.
- Avoid reskinning sensitive/confusing areas in Min mode.
- Keep route changes, right rails, timeline controls, and composer layout stable.
- Ensure text remains readable in both light and dark themes.

### Remilia font and visual asset pass

Labels: `ux`, `docs`.

Targets:

- Bundle and apply approved Remilia-style fonts/assets where appropriate.
- Keep bundled assets documented and license-compatible.
- Preserve readable fallbacks if custom fonts fail to load.

### RemiNet Chat visual integration

Labels: `reminet`, `chat`, `ux`.

Targets:

- Make the chat sidebar match the new aesthetic presets.
- Keep controls legible in light/dark mode.
- Avoid covering X controls or crowding the right rail.
- Preserve existing chat auth/socket behavior.

### Beetol and RemiStats polish

Labels: `beetol`, `reminet`, `ux`.

Targets:

- Align Beetol panel, RemiStats badges, sounds, poke indicators, and cooldown states with the new aesthetic system.
- Keep status/cooldown text clear at small sizes.
- Preserve existing RemiNet auth and cooldown behavior.

### Remilia Wiki flow follow-up

Labels: `remilia-wiki`, `ux`.

Targets:

- Clearer decision tree: create new page vs add section to existing page.
- Keep current template/search behavior as fallback.
- Avoid taking ownership of wiki authentication unless a safe extension-friendly flow becomes available later.
