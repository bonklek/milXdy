# milXdy 0.1.3 Private Release Notes

Status: planned next beta.

Public theme: update UX, beta polish, and screenshot-ready documentation.

## Release Goals

- Make updates less confusing while preserving extension storage.
- Make recent RemiNet poke reciprocity visible on X/Twitter.
- Give testers clearer bug-report and screenshot/reporting flows.
- Start posting public feature plans through the roadmap and GitHub Discussions.

## Planned Features

### Guided updater

User-facing behavior:

- Suite tab shows update status.
- **Download** opens the latest GitHub release zip or release page.
- **Steps** copies safe in-place update instructions.
- **Reload** reloads the existing unpacked extension after files are replaced.

Patch-note wording:

- "The Suite tab now guides manual beta updates so users can keep the same extension folder and preserve settings, stats, and Beetol tokens."

Known limits:

- This is not true automatic updating.
- The user still has to replace files in the same folder.
- Loading a fresh folder can still create a new extension identity.

### Incoming RemiNet poke indicators

User-facing behavior:

- RemiNet badges can show a small "poked you!" indicator when a recent RemiliaNET poke notification matches that account.

Patch-note wording:

- "RemiNet badges can now surface recent incoming poke notifications, making poke reciprocity easier to notice."

Known limits:

- Best-effort matching from notification sender handles.
- Limited to recent notifications in the active poke window.
- Not a complete all-time poke history.

### Bug-report UX cleanup

User-facing behavior:

- Diag tab reports bugs through GitHub or X.
- Optional LLM-assisted prompt helps users produce a reproducible report.

Patch-note wording:

- "Bug reporting is clearer, with GitHub/X paths and optional LLM-assisted drafting from the Diag tab."

### README screenshots

Screenshot targets:

1. Popup Suite/Wiki overview showing update and tabbed settings.
2. Remilia Wiki/Grok workflow or draggable Wiki shortcut.
3. RemiNet badge with poke button, incoming poke flag, or Beetol panel.
4. Diag tab report controls or Postreader/Maxxer visual feature.
