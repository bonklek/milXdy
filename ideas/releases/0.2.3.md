# milXdy 0.2.3 Private Release Notes

Public theme: reliability, recovery, performance, and accessibility across the prepared app platform.

## Release Inventory

- Complete code-level remediation for all 43 UX and feature reliability audit findings.
- Isolate app lifecycle, surface-delivery, and idle-task failures so one app cannot strand shared work.
- Make startup, network, storage, worker, speech, and local-file workflows cancelable and recoverable.
- Return Beetol Hunt results before background reconciliation and preserve the final reward before cooldown.
- Bound RemiNet Chat authentication and WebSocket opening, reuse recent valid authentication, and make logout authoritative.
- Hide RemiStats poke controls until the visible account is confirmed as a RemiliaNET identity.
- Reserve RemiStats action-row poke scaffolding before lazy delivery and restore flexible tweet-header width so poke placement and handle truncation remain stable.
- Recover Music artwork from embedded local-file metadata, version stale parser results, and key negative artwork checks to file size and modification time.
- Remove the legacy popup RemiNet Chat enablement mirror; Apps & Features owns app enable/disable state.
- Rename the updater handoff action to **Open in LLM**.
- Generalize regression coverage around registry app enablement, profile-pack section support, Music artwork cache policy, filesystem layout, and Post-reading token offsets; keep exact security/privacy/release contracts intentionally specific.
- Remove X Like-animation, mutation-rescan, and relational-selector hot paths.
- Improve rail overflow, compact ordering controls, Root Visual grouping, dark surfaces, reaction state, and Wiki read-aloud expansion.
- Preserve the Firefox/Waterfox, browser-specific updater, fullscreen DM media, and Tweet PNG fixes prepared after `0.2.2`.
- Finish the App SDK and app-launcher follow-through needed for the app platform to be a stable base for later packages.
