# Custom Pet pipeline provenance

The Pets Maker request format, import adapter, template contracts, deterministic
validation, and cache/resume tooling are included as source in this repository.
The adapter uses the standard v2 pet row and frame contract, transparent-cell
validation, safe paths, explicit template selection, and user-reviewed handoff.

Imported material retains its applicable Viral Public License notices. The
bundled templates describe registration and motion requirements; they contain
no character sprites or private reference images.

Private integration runs, generated pet packages, review records, user inputs,
and local source inventories are excluded from public source and release
archives. Those records are not distributed as test fixtures or publication
approvals. Run-specific visual review remains separate from deterministic
validation.
