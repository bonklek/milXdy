# Miladychan Portal User Guide

Miladychan Portal browses public Miladychan boards, threads, posts, and media from the shared side rail.

## Where To Find It

- Enable and pin **Miladychan** from Apps & Features.
- Open **Miladychan** from the side rail on X/Twitter.

## Common Tasks

- Browse active board summaries for configured Miladychan boards.
- Open a board to view its thread list.
- Open a thread to read posts and media previews.
- Use thread headers and media links to open the native Miladychan site.
- On a board or thread, write a text-only local draft, confirm the visible destination, then explicitly submit it anonymously or copy it and open native Miladychan.
- Adjust the panel layout and theme; these choices are stored locally.

## Notes

The portal's direct text-only submit uses no Miladychan session, RemiNet login, cookies, tokens, X/Twitter, wallet, or extension identity. It never uploads media. It keeps drafts locally until you explicitly discard them; failures keep the draft and show the upstream result. Native Miladychan remains available for CAPTCHA, session-bound, media, unsupported-board, and full-board behavior.
