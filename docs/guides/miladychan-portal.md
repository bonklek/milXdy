# Miladychan Portal User Guide

Miladychan Portal browses public Miladychan boards, threads, posts, and media from the shared side rail.

## Where To Find It

- Enable and pin **Miladychan** from Apps & Features.
- Open **Miladychan** from the side rail on X/Twitter.

## Common Tasks

- Browse active board summaries for configured Miladychan boards.
- Open a board to view its thread list.
- Open a thread to read posts and media previews.
- In a thread, the upper-left back button names its board (for example, **← /milady/**) and returns to that board. The thread title controls put a **↖** board-back button immediately beside **JUMP**; the Portal header retains the native-tab button beside refresh.
- In a thread header, click **Watch this thread** to save it to the local-only watched-threads list on the Portal home view. When the Portal is opened or refreshed, its dock icon shows the number of newer posts found in watched threads; opening a watched thread marks its loaded posts seen. Watching does not poll, notify, or use an account/session.
- On a board or thread, write a text-only post, review the visible poster name (default: `milXdy`), then click **Post**. A final dialog confirms the visible destination immediately before submission. Use the header's native-tab button for CAPTCHA, media, session-bound, or full-board behavior.
- In a thread, use the down-arrow **JUMP** control beside the title to reach the latest post; the bottom reply composer has a matching up-arrow **JUMP** control to return to the title. Click a post number to focus the bottom reply form with that post's `>>123` reference format. Visible `>>123` references in posts are links that jump to the loaded post.
- Adjust the panel layout and theme; these choices are stored locally.

## Notes

The portal's direct text-only submit uses no Miladychan session, RemiNet login, cookies, tokens, X/Twitter, wallet, or extension identity. It never uploads media. Failed submissions and the user-selected watched-thread list are retained locally; watching never creates background requests, notifications, or cross-device syncing. Native Miladychan remains available for CAPTCHA, session-bound, media, unsupported-board, and full-board behavior.
