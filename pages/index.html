A Remilia-oriented layer for X/Twitter

milXdy brings Wiki tools, post reading, RemiNet features, Maxxer, docked apps, music, and visual controls into one unpacked extension.

Download latest release Read the user guide
GitHub beta Install locally; milXdy is not distributed through the Chrome Web Store or Firefox Add-ons.

Chrome · Brave · Edge

Install in four steps

  1. ↓01DownloadChromium ZIP
  2. 02UnzipPermanent folder
  3. ＋03Load unpackedchrome://extensions
  4. ↻04RefreshOpen X tabs

Keep the same folder. Enable Developer mode before choosing Load unpacked. Removing milXdy or loading another folder can reset extension-local settings and login state. Firefox 142+ beta users should follow the temporary add-on guide.
