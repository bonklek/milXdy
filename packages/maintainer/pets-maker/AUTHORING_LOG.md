# Pets Maker package provenance

Pets Maker owns its lifecycle, request editor, compositing, validation, styles,
and icon. It uses the public App SDK and reads public Maker metadata only after
an explicit user action. It is disabled by default and enabled separately.

## Rail icon

The packaged `assets/remy.png` is unmodified Remy artwork distributed under the
Viral Public License. Its exact bytes are pinned in the package manifest.
Private source inventories, local preview filenames, and review records are
excluded from this public package.

Catalog installation preserves explicit enablement and selection choices.
The checked-in content bundle permits repeatable source builds without relying
on an untracked prior build.
