# Current asset status

The publication candidate ships contributor guidance, schemas, tokens, code
recipes, and synthetic validator examples. It does not yet bundle a curated
default artwork library.

That does not block local authors. A custom package may use user-selected images,
icons, fonts, audio, and generated derivatives by declaring the files it ships.
Catalog metadata and provenance records are optional unless the author wants
repeatable sharing or upstream consideration.

## Existing milXdy assets

Existing default milXdy media remains part of the VPL project. If a maintainer
wants to promote an existing file into a separately versioned official visual
bundle, the file should receive the same explicit source/hash record as any
other upstream entry. That catalog housekeeping is not required for a user to
build a local custom package.

## Public references

Public sites and cultural references can inform composition, density, palettes,
and interaction patterns. Local authors decide what material they use and are
responsible for their choices. The upstream project does not treat visual
similarity or public availability as proof that a file is eligible for default
distribution.

## Included examples

The synthetic source, Music-headphones derivative, CSS frame, and package files
under `fixtures/` exist to make the contributor workflow executable. They are
not claims about an external artwork or a requirement that local authors use a
catalog.
