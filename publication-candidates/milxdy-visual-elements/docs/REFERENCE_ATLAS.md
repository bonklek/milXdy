# Public reference atlas

This atlas records design principles, not a project endorsement or a license
decision. Local authors choose their own inputs. Files proposed for
default/upstream distribution receive a separate VPL review.

| Public source | Reusable design observation | Asset boundary |
|---|---|---|
| [Milady Maker](https://miladymaker.net/) | Constrained character taxonomy, compact small-web framing, readable silhouettes, and coherent variation. | Useful local reference; exact VPL scope is checked only for upstream promotion. |
| [Milady Maker design notes](https://blog.remilia.org/milady-maker/) | Character system and design vocabulary. | Reference only unless exact file evidence is added. |
| [Remilia Wiki](https://wiki.remilia.org/Main_Page) | Archival density, predictable headings, revision/source visibility, and file-level records. | Check every file page and exception. |
| [Remilia](https://www.remilia.org/) | Red/white institutional announcement register and thin rules. | Reference only. |
| [CULT](https://cult.inc/) | Black/red operator console, compact mono tools, and one-pixel rules. | Reference only. |
| [CHEESEWORLD description](https://blog.remilia.org/cheeseworld-p2p-press-release/) | Constrained remix and deliberate degradation as named operations. | Reference locally; “copyleft” alone is insufficient for default/upstream VPL review. |
| [RemiliaNET design notes](https://blog.remilia.org/remilianet-alpha-design-notes/) | Bounded identity variation and sound as semantic feedback. | Reference only. |
| [Miladychan](https://miladychan.org/) | Realtime imageboard density, context-specific reactions, compact modes, and mobile controls. | Reference only. |

## Translation rule

1. Link the public source.
2. Describe the observed principle in original language.
3. Build a new semantic HTML/CSS/JS example.
4. Label whether an example is local-custom or upstream-default.
5. Do not imply that a local example is an official default asset.

The guide supports several compatible registers. It does not claim that one
source defines a universal style or official affiliation.
